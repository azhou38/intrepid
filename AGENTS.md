# Destination and spot content

The rules for the data in `src/data/` are in three files:

- `COVERAGE.md` — which destinations and spots belong, where each goes, ranking, finding what is missing, coordinates
- `WRITING.md` — names, fields, voice
- `IMAGES.md` — every photo: headers, "Why visit" photos, spot photos, and the header workflow

`PIPELINES.md` describes the background agent roles that apply them.
