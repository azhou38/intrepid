# Spot bio writer brief (Victoria, Pipeline C step 2)
Role: .claude/agents/copy-writer.md. Read WRITING.md "Voice" and "Writing a spot" (bio rules) first.
Input: your in-N.json: ~24 spots, each with id, name, category, destination, bio_draft (stale; a hint only), facts [{claim, source_url}], access_note, unresolved, cost fields.
Output: curation/victoria/quill/bios/out-N.json, a list of {id, bio, name_fix?, drop_reason?, gaps?}.
Rules: ONE sentence, at least 10 words, roughly 100-120 characters (it must fit three lines of a carousel card at 375pt, about 120 chars), saying what it is, where, and the one thing worth a stop. Write ONLY from the `facts`; never use a claim from bio_draft that is not in facts (drafts contain errors). Never name a source. No marketing filler, no unbackable superlatives, no transient promises (a closed attraction, a temporary exhibition, a seasonal event is not promised; if a key part is closed per access_note, describe what is there now or set `gaps` and write a bio that stays true). A fact that matters to a visitor (guided-tour only, open certain days, hike-in) belongs in the bio if it fits. If the facts are too thin for an honest bio, write the best true sentence from what is sourced and put the reason in `gaps`. If the place's name has changed (facts say so), put the new official name in `name_fix`. If facts show it is closed to visitors or is not what was placed, set `drop_reason`.
Final message at most 5 lines: file written, counts, spots with gaps/drop_reason by id.
