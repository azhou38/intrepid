Repo: /Users/alexzhou/Developer/mobile-wellington. Read COVERAGE.md "Verifying coordinates" first. Input `curation/sa/pinwork/in-<N>.json` (list of spots: id, name, category, bio, wiki, quill_provisional (a draft point or null), pin_hint_notes (what the researcher found about where the place is), search_hint (a town-level point)). The shared resolver `scripts/curation/resolve-pin.py` is useless right now (Overpass main is down), so you find each point yourself, with these rules:
- Sources, best first: an OpenStreetMap feature with the right name and type (use the Overpass mirrors `https://overpass.openstreetmap.fr/api/interpreter`, `https://overpass.kumi.systems/api/interpreter`, `https://overpass.private.coffee/api/interpreter`, `https://maps.mail.ru/osm/tools/overpass/api/interpreter`; send a User-Agent `wellington-curation/1.0 (alexzhou38@gmail.com)`; query `nwr["name"~"<distinct word>",i](around:15000,lat,lon);out center tags 20;` and use `out geom` / the way's middle for trails); the place's own Wikipedia/Wikidata coordinates (when the article is about this place, not a town or district); geotagged Commons files of the place itself (median); the managing agency or tourism listing's address, geocoded. Nominatim only for a street address or a town, at most one request per 3 seconds (other agents share it), never in a loop without sleeping.
- Type rules: a summit/lookout ON the peak or viewpoint node; a beach at its OSM natural=beach way centre or the access car park; a trail/walk at the midpoint along its OSM route (middle vertex of the way/relation geometry), a park at its main visitor point (car park, day-use area, campground), never the centroid; a town at its place node; a museum/building at its node or address; silo art at the silos; a sculpture at its node.
- Confidence: HIGH = two independent sources within 100 m; MEDIUM = one precise OSM feature of the right type and name, or one Wikipedia/Wikidata point for this very place; LOW = anything else (town-level, centroid, single unnamed geotag). Never give a point from memory, never rounded (>= 4 decimals), never another spot's or a town's point for an attraction. Check you did not give two spots the same point (move the lesser 25 m or merge them in a note).
- Do not edit any file except your output. Do not run git.
Output `curation/sa/pinwork/out-<N>.json` = `{ "<id>": { "lat": n, "lon": n, "confidence": "HIGH|MEDIUM|LOW", "source": "<what feature/page, with OSM id or URL>", "note": "..." } }`; a spot you really cannot place: `{ "lat": null, "lon": null, "confidence": "NONE", "note": "why" }`. Write the file incrementally (every ~10 spots) so progress is never lost. Validate it parses. Final message at most 8 lines: counts by confidence, the NONE ids, any source blocked.
