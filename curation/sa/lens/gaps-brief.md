Repo: /Users/alexzhou/Developer/mobile-wellington. Rules: IMAGES.md "When Commons has no suitable photo" and "The four checks". Input `curation/sa/lens/gaps/in-<N>.json`: slots where Commons gave nothing that passed. Commons was already searched; do NOT re-search Commons except for a different file you can name. Work the tiers in order: (1) openly licensed (CC0/PD/CC BY/CC BY-SA): Openverse (`scripts/openverse-search.py`, needs >= 1280 px original: header >= 1500), Wikimedia-adjacent sources, Unsplash/Pexels; (2) official/tourism photos (parks.sa.gov.au, southaustralia.com, regional tourism boards, the operator): use `curl -A "Mozilla/5.0"` to read pages and image CDN originals, take the original (drop `-768x576` style suffixes), verify real pixel size; these are not openly licensed: record owner, page and licence "official photo, permission not confirmed". If a site answers 403/"Just a moment", list it under needs_browser with its URL (agents here cannot use the in-app browser).
For each slot find at most 3 candidates that you have LOOKED at (download to `curation/sa/lens/gaps/img/<slot with colons replaced by _>-<n>.jpg`, Read it) and that pass the four checks (right place proven, shows the exact reason, spectacular/wide, real current colour photograph, a person/animal not the main focus, no watermark/text overlay). Never a stand-in. If none passes, say so.
Output `curation/sa/lens/gaps/out-<N>.json` = `{ "<slot>": [ { "local": "<path under curation/sa/lens/gaps/img>", "width": n, "height": n, "page": "<URL of the page the photo is on>", "by": "<owner/author>", "licence": "...", "official": true|false, "why": "<what it shows>" } ] }`, written after every few slots. Do not edit anything else, no git. Final message <= 8 lines: slots filled / still empty, every needs_browser URL, copyright-risk (official) photos used.
