# Tasmania destination writing brief (input curation/tas/dest/in-<G>.json; output curation/tas/dest/out-<G>.json)

You research and write the full destination entry for each destination in your input file, per WRITING.md ("Writing a destination", "Voice"). Facts from sources only (fetch with `npx tsx scripts/curation/fetch.ts <url>`: Wikivoyage, Parks and Wildlife Service Tasmania parks.tas.gov.au, Discover Tasmania discovertasmania.com.au, the operators' own sites); NEVER name a source in the text; no marketing filler, no unverifiable superlatives. The spots listed under each destination are its spots (their bios are drafts): write the destination so it does not repeat them word for word.
Output a JSON list, one object per destination:
{ id, name (keep given), icon (one emoji), tagline (one sentence), description (3-4 concrete sentences: what it is, why people go, one distinctive fact, no spot-list dump), whyVisit (exactly `whyVisitCount` reasons, strongest first, 2-8 words each, each starting with an action verb: "See ...", "Walk ...", "Cruise ...", about something a photo can honestly show and ideally one of the destination's spots), highlights (same count, 2-3 words each), whyVisitSubjects (same count: the specific thing/place each reason shows, for the photo search), goodToKnow (exactly 3 { icon (emoji), title, detail } practical first-timer tips: booking, weather, transport, safety, park passes; specific, sourced), bestMonths (array of 1-12 for Tasmania's southern-hemisphere seasons from guide consensus), bestTimeBlurb (contains exactly one "{months}" placeholder), seasonalTags (only if a real recurring pattern, else omit; use hemisphere-relative tags), sources:[urls], unverified:[claims you could not verify] }.
Today is 2026-10-20: check closures or booking rules that apply now. Parks Pass facts: check current prices on parks.tas.gov.au. Write ONLY your out file. Final message: any destination you think fails the bar and why.
