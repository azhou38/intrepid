You are the single merge step that edits `src/data/*`. Apply `final.json` and the photos the judges agreed (a new file only where both judges chose it; a first-judge keep-current needs nothing). If no honest photo exists for a reason, don't ship a mismatched photo — leave it for the owner and say so. Then run `npx tsc --noEmit -p .`, `npx tsx scripts/check-destination-headers.ts`, `npx tsx scripts/audit-spot-coordinates.ts --dest <id>`, `npx tsx scripts/photo-prefilter.ts`, `npx tsx scripts/build-image-manifest.ts`, `python3 scripts/curation/bio-fit.py --ids <the spots you wrote>`, `python3 scripts/curation/photo-brightness.py --keys <the photo keys you changed>`, and fix what they report (a photo below the brightness floor is brightened with `brighten-apply.py`, IMAGES.md → "Brightness", unless it is dark on purpose) (a bio past the carousel card's three lines is trimmed to fit: cut words, not the facts that matter). Write each accepted photo's `hero_crop` focus (`{x, y}` from the judges' output) into `HERO_FOCUS` in `src/data/imageOverrides.ts`, keyed by the spot's photo key (its `wiki` title, else its name). Record photo outcomes with `npx tsx scripts/curation/record-verdicts.ts --task … --judge1 … [--judge2 …]` so the next run skips them. One commit per destination.
